# iBookTrack
A unified Warehouse Management System (WMS) and Executive Dashboard developed for Innodata. This platform synchronizes physical book digitization workflows (8-step pipeline) with real-time backend data to eliminate inventory loss and automate status reporting.

## 🚀 Overview
A high-performance web application designed to manage the 8-step book digitization pipeline at Innodata. 

## 🛠 Tech Stack
- **Frontend:** React / Next.js (Figma Design Integrated)
- **Backend:** Node.js (with Client Backend API Authority)
- **AI Tooling:** Windsurf AI (Premium)
- **Database:** [Your Database Choice]

## 📋 Core Modules
1. **Live Executive Dashboard:** Real-time Mustang/Jaguar status reports.
2. **Smart Intake:** ISBN-to-Lot validation via backend sync.
3. **Chain of Custody:** Digital station handshakes to stop book loss.
4. **QA Remark Portal:** Direct database flagging (Replacing Excel logs).
5. **Hash-Check Guard:** Verified PDF transmission monitor.
